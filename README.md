## 🧩 Flagship Project

### [🔐 Auth-as-a-Service Platform (AaaS)](https://github.com/thulasidharan96/Auth-as-a-Service)

A production-ready authentication system designed as a reusable infrastructure component.

- **⚡ Features:** JWT, OAuth2, Passkeys, RBAC, Token lifecycle, Redis caching, Secure API design.
- **🛠️ Tech Stack:** FastAPI, PostgreSQL, Redis, Docker.
- **🎯 Goal:** To build a scalable authentication layer that can plug into any application — similar to a lightweight identity provider.
